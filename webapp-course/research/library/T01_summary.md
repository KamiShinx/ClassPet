# T01 summary — Figma UI UX Essentials (Bring Your Own Laptop)

**Sampled 6 of 32 videos: 2 core, 1 useful, 3 skip.**

This is Dan Scott's "Figma Essentials" course chopped into a YouTube playlist: one 177-minute main course
(`kbZejnPXyLM`, the free extract of a paid 111-video course) plus 31 short clips. The short clips are not
independent lessons — several are word-for-word re-cuts of segments already inside the main course
(`_d8GG2QZYAM` = main course 5:39-9:21, `Yo3tpdiXJQk` = main course 2:49-2:56, and `UU_eyUGWIEI` matches
0:28-0:31). That pattern held across every duplicate I checked, so I've assumed it holds for the rest too
(see below).

## The videos, ranked

1. **What is Low Fidelity Wireframes vs High Fidelity Wireframes in Figma** (`UU_eyUGWIEI`, 3.2 min) —
   `core`. The one genuinely tool-agnostic concept in the whole group: sketch cheap and gray before you
   build pretty, so feedback is about the flow, not the colors. Directly explains "low vs high fidelity"
   from the brief's own example list.
2. **Free Figma UX Design UI Essentials Course** (`kbZejnPXyLM`, 177.7 min) — `useful`. Three short
   segments worth lifting for a guide: UI vs UX (9:52-15:09), persona + task flow / why you scope a brief
   to one flow (15:41-24:09, no Figma-mechanics equivalent elsewhere in the playlist), and the wireframe
   segment duplicated by #1. Everything else — frames, the Type tool, rectangle/color-picker mechanics,
   importing icons, Pages, prototype transitions and easing, comment pins, Teams/pricing — is Figma
   software operation the kids will never touch, since Gemini writes their UI code.
3. **Frames vs Groups in Figma** (`uvUnXa_uBNQ`, 10 min) — `skip`. Figma's own object model (clipping,
   nesting, constraints); not a UI concept, and the presenter himself calls it confusing.
4. **What is Figma?** (`_d8GG2QZYAM`, 4.5 min) — `skip`. Product pitch, duplicate of the main course.
5. **Share Editing with other UX designers in Figma** (`Yo3tpdiXJQk`, 7.7 min) — `skip`. Figma's
   Drafts/Teams/pricing structure, duplicate of the main course.
6. **Do I Need to Know Adobe Illustrator to Use Figma?** (`p-onEUMZW7I`, 5 min) — `skip`. Two enterprise
   tools the kids won't use.

**Duplicates noticed:** `_d8GG2QZYAM`, `Yo3tpdiXJQk`, and `UU_eyUGWIEI` are all literal re-cuts of
segments inside `kbZejnPXyLM` — the channel appears to slice its paid course into free standalone clips
for SEO. Expect the same for other short clips whose titles match a beat in the main course.

**Nothing surprising** except how strong the split is: exactly one short clip in the sample carried a
transferable idea, and it's a duplicate of material already inside the long course. The channel's real
subject is Figma the application, not UX process.

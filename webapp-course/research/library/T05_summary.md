2. **UX Design Process Explained** (`-_lK35Wczfc`, core) — the standard 5-stage design-thinking process

3. **User Personas in UX Design** (`3PkwYR1xuGk`, core) — short (6 min), clear 4-part persona template
   (personal/professional detail, user environment, psychographics) plus a worked pain-points example.
4. **TYPOGRAPHY PRINCIPLES** (`C5h1ZE1AhlI`, core) — typeface vs font, serif/sans-serif, weight/hierarchy;
   clean and transferable to any web page.
5. **Figma Auto Layout** (`gJ6cvzZ0ewQ`, useful) — every setting shown (direction, gap, padding, fill/hug,
   alignment) is flexbox reasoning in disguise; worth a segment if a guide makes that bridge explicit.

## Surprising
Every Ali Hassan caption file is a badly-looped Whisper transcript (heavy repetition, code-switched
Hindi/English confusing `small.en`) — real content had to be read through the noise rather than off it.
Even so, the concept videos (color, typography, process, personas) come through clearly; the pure-Figma
videos (basics, components, glassmorphism, navbar prototyping) stay tool-specific no matter how you read
them, so the garbling didn't actually change any verdicts. One title, "Build a Killer UI/UX Design
Portfolio," is exactly the kind of career/portfolio content the brief already rules out — good that it also
had no captions, since it saved a false-positive read.

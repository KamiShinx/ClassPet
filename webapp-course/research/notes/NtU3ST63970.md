# Build a Full ERP System From Google Sheets in Minutes (No Code AI App Builder) (Mohammad Rameez Imdad, 18.5 min)

**What it is:** a promo screen-recording clickthrough of the creator's own paid, proprietary "AI App Builder" SaaS product, which turns a registered Google Sheet into a branded CRM/ERP dashboard. Not a tutorial, not an AI-build log.
**Substance:** thin: it is a UI tour of a finished commercial tool. No code is written on screen, no backend concept is explained in teaching terms, and the "No Code AI App Builder" in the title is accurate — the viewer is sold the tool, not shown how to build one.

## Ideas, in the video's order
- [0:00:00] Pitch: convert "any raw Google Sheet" into a CRM/ERP dashboard "within just a few clicks" (marketing claim, generic).
- [0:00:28] You can register 10, 20, "unlimited" sheets, each becoming its own CRM/ERP instance inside the builder — multi-tenant SaaS idea, not something a kid needs.

- [0:04:32]-[0:04:58] "AI write prompt": the tool's AI reads your tables and drafts an app-logic prompt for you to review/edit before building — a genuine, reusable pattern (AI drafts the ask, human edits it before it's used), but again opaque here.

## For our class (14-15, Gemini writes the code, Apps Script + Sheets)
### Backend concepts it shows or explains
Two-way sync between a dashboard and its Sheet (sheet is the database, dashboard reads and writes it); opening a spreadsheet by its Sheet ID; schema/relationship inference across tabs (a soft version of foreign keys); role-based permission matrices scoped to specific sheets and CRUD actions; "when a row is added, send an email" trigger, which is precisely what Apps Script `onFormSubmit`/`onEdit` triggers do; "AI turns a plain-language KPI description into a count/filter condition" is a good mini-demo of what Gemini will do for kids constantly.

### Becomes something kids do (activity, mini-project, milestone), concrete enough to run next week
A small class-roster or attendance sheet (2-3 tabs) where kids build basic CRUD by hand with Gemini's help (read rows, add a row, update a cell) instead of any no-code tool, then add one `onEdit` or `onFormSubmit` trigger that sends an email or writes a log row — this mirrors the "row added → automation" idea at [0:16:26] without the proprietary product.

### Traps a kid will hit
Kids may ask "why can't we just use a tool like this" instead of building it — worth an explicit "this is a paid finished product, not our method" note up front. The live two-way sync to a shared Sheet, shown with a single user editing at [0:01:07], never addresses what happens when a whole class edits concurrently — a real concurrency trap the video hides.

### Doesn't transfer, and why
The entire video runs on a closed, hosted SaaS product with its own login, billing, and API-key management — nothing here is buildable by a 14-year-old in Apps Script. The adult ERP/HR/payroll/CRM domain (salaries, HR systems, permission matrices for a business) is architecture reference at best, not a project a teen wants to build.

## Honest caveats
No real AI-build process is shown anywhere in this 18.5-minute video — it is a UI clickthrough of a finished paid product. Steps like "AI write prompt" and "AI Define" clearly call an LLM behind the scenes, but the video never shows a prompt being typed, an error appearing, or a fix being made; there is nothing here that satisfies "how AI-assisted building actually goes." Every backend concept listed above is inferred from watching the finished UI, not from anything the video explains in teaching terms.
